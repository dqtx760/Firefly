### gmshop-edge源码

自托管、单部署、单租户的**数字商品自动发货商城**。一次部署同时包含前台商店、客户账户、结账与履约（发货）、以及权限化的管理后台。

仓库 https://github.com/GMWalletApp/gmshop-edge

核心发货能力：

- **卡密/激活码/账号类**：库存商品原子分配加密预设文本，不会超卖
- **上游同步发货**：从 ACG V4 Open API 或 独角数卡 Dujiao Next 同步商品，按同优先级账号池履约
- **私有文件交付**：R2 存储，带授权、次数/时限受限的下载
- **自动化类商品**：脚本执行、部署、资源开通，`none / optional / required` 三种产物策略
- **权益策略**：永久、限期、限次、无限、免费、一次性、用户续期可组合，金额不用浮点

支付适配：Stripe、GMpay、EPay 等；邮件走 SMTP / Resend / Postmark / SendGrid / Mailgun / Cloudflare Send Email，带 Queue + Cron 有界重试。

**部署2条路**
1. Cloudflare Workers（原生路线）：Worker + D1 + KV + 私有 R2 + 一个业务 Queue（含死信队列）+ Cron Triggers 
2. Bun / Nitro Docker 容器（8 月新增）：compose.yml 已提供

**两个要注意的点**

1. **作者明确标注仍在活跃开发中**，生产环境需要你自己准备供应商凭据、备份、监控，并做真实支付的验收测试——别直接上生产。
2. **GPL-3.0 协议**，有传染性。如果要做闭源商业二次开发，这个协议是个硬约束，得先确认清楚。
