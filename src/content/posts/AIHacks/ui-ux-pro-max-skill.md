## 5分钟安装教程，新手也能搞定
安装过程非常简单，只要两步就能搞定：
### 1. 下载技能源码
打开终端执行克隆命令，把技能仓库下载到本地Claude技能目录：
```bash
git clone https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git C:/Users/Administrator/.skill-hub/ui-ux-pro-max-skill
```
### 2. 同步到系统
克隆完成后在Claude里执行同步命令，把技能同步到Claude、Codex等工具的配置目录：
```
/skill tongbu
```
同步完成后输入`/skills`查看技能列表，出现`ui-ux-pro-max`就说明安装成功了。
