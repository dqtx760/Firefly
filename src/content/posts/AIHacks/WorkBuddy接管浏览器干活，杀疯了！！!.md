### **案例**1

```
打开我已登录的公众号后台，汇总2026年以来各篇文章的标题、阅读量、点赞数、转发数，形成一个Excel表格给我
```


### **案例**2

```
打开我已经登录的抖音，找出最火的5篇WorkBuddy教程，把评论区里的高赞问题抓出来，看看用户现在最头疼的是什么。
```

### **案例**3

```
打开我已经登录的BOSS直聘，搜索”上海+量化交易”相关岗位，帮我收集上海最近发布的30个有效岗位。

把岗位名称、公司、城市、薪资、经验学历要求、岗位职责和任职要求整理成Excel。

最后分析一下，现在企业招聘量化交易相关人员时最看重哪些能力、经常要会有哪些要求?然后把所有东西最终输出成一份完全PDF报告。
```
