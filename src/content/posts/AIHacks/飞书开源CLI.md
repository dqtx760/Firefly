让人类和 AI Agent 都能在终端中操作飞书。覆盖消息、文档、多维表格、电子表格、幻灯片、日历、邮箱、任务、会议、Markdown 等核心业务域，提供 200+ 命令及 24 个 AI Agent [Skills](https://github.com/larksuite/cli/blob/main/skills)。

项目地址
https://github.com/larksuite/cli

### 安装与配置

**第 1 步 — 安装**

```shell
npm install -g @larksuite/cli
```

**第 2 步 — 配置应用凭证**

> 在后台运行此命令，命令会输出一个授权链接，提取该链接并发送给用户，用户在浏览器中完成配置后命令会自动退出。

```shell
lark-cli config init --new
```

**第 3 步 — 交互式登录**

> 同上，后台运行，提取授权链接发给用户。

```shell
lark-cli auth login
```

![](https://gitee.com/da-qiang-classmate/typora/raw/master/image/20260516004325433.webp)


**第 4 步 — 验证**

```shell
lark-cli auth status
```

### 在Claude code使用

**消息与沟通**
- "帮我搜下云文档里关于 XX 的文档"
- "帮我搜下飞书技术笔记知识库里关于chrome的文档"
- "给张三发送消息：明天的会议取消"
- "查看我最近未读的消息"
- "在某某群聊里发一条消息：本周五下午3点团建"

**文档操作**
- "帮我创建一篇飞书文档"
- "在飞书文档里插入这张图"
- "帮我搜索所有包含'项目计划'的文档"
- "把这段内容追加到我的笔记文档里"
- "创建一个多维表格，包含姓名、部门、入职时间三个字段"
- "读取我昨天创建的文档内容"

**日程管理**
- "查下我今天的日程"
- "明天下午3点帮我安排一个会议，参与人：张三、李四"
- "查看本周所有的会议安排"
- "取消后天的产品评审会议"

**文件与云盘**
- "把这份PDF上传到我的云盘"
- "在云盘搜索文件名包含'报告'的文件"
- "创建一个共享文件夹，名字叫'项目资料'"

**任务与协作**
- "创建一个任务：完成Q2总结报告，截止日期本周五"
- "查看我负责的所有进行中的任务"
- "把这份文档分享给整个团队"

整个过程自然流畅，AI直接执行，不需要你在多个工具之间来回切换。

**实际对话示例**

> **你**：帮我搜下飞书技术笔记知识库里关于chrome的文档
> 
> **Claude**：好的，我来帮你搜索... 找到了3篇相关文档：
> 1. Chrome浏览器性能优化指南
> 2. Chrome开发者工具使用技巧
> 3. Chrome扩展开发文档
> 需要我打开哪一篇？

> **你**：创建一个多维表格，记录团队值班安排，包含日期、姓名、备注三个字段
> 
> **Claude**：已创建完成！表格链接：https://xxx 需要我现在帮你填充这周的值班数据吗？

缺点当然也有：每次添加新权限需要重新授权，飞书应用的管理也需要一点学习成本。
