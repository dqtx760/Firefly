## 🔧 Qwen Code 接入配置

我成功接入了Qwen Code与蚂蚁百灵大模型，以下是完整的配置步骤：

### 配置文件路径

> `C:\Users\Administrator\.qwen\settings.json`

### 完整配置代码

```json
{
  "env": {
    "LING_API_KEY": "你的百灵API令牌",
    "QWEN_CUSTOM_API_KEY_OPENAI_HTTPS_API_OPENAI_COM_V1": "你的百灵API令牌"
  },
  "modelProviders": {
    "openai": [
      {
        "id": "Ling-2.6-1T",
        "name": "Ling-2.6-1T",
        "baseUrl": "https://api.openai.com/v1",
        "envKey": "QWEN_CUSTOM_API_KEY_OPENAI_HTTPS_API_OPENAI_COM_V1"
      },
      {
        "id": "ling-2.6-1t",
        "name": "Ling-2.6-1T",
        "model": "Ling-2.6-1T",
        "baseUrl": "https://api.tbox.cn/api/llm/v1",
        "envKey": "LING_API_KEY",
        "generationConfig": {
          "temperature": 0.7,
          "topP": 0.9,
          "maxTokens": 4096
        }
      }
    ]
  },
  "defaultModel": "ling-2.6-1t",
  "$version": 3,
  "security": {
    "auth": {
      "selectedType": "openai"
    }
  },
  "model": {
    "name": "ling-2.6-1t"
  }
}
```

### 配置说明

| 配置项 | 说明 |
|--------|------|
| `LING_API_KEY` | 蚂蚁百灵API访问令牌 |
| `QWEN_CUSTOM_API_KEY_OPENAI_HTTPS_API_OPENAI_COM_V1` | Qwen Code 自定义API密钥配置 |
| `baseUrl` | API请求基础地址 |
| `temperature` | 温度参数(0.7)：控制回答的随机性 |
| `topP` | Top-P采样(0.9)：控制词汇选择的多样性 |
| `maxTokens` | 最大生成长度(4096) |

该模型知识覆盖面广、储备扎实，分析维度更深、逻辑推理能力突出，输出内容精准优质；短板为响应速度偏慢。更适配复杂代码重构、深度文档撰写、核心业务设计、多轮推演类高难度复杂场景。
