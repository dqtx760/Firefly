Share to NotionNext 插件教程
01

痛点分析

✍️ 写作体验

Obsidian 写 Markdown 丝滑顺畅，沉浸式写作体验极佳

🚀 发布困难

想同步到 NotionNext 发博客，需要复制粘贴、排版错乱

😫 手动搬运

属性对不上、容易漏内容，折腾半天还容易出错

👉 一键同步，告别手动搬运！

02

前置准备：Notion API

  • 01
    创建 API 集成

    访问 notion.so/my-integrations 创建新的集成

  • 02
    复制 API Token

    创建成功后，复制生成的 Secret Token（妥善保管，不要泄露）

03

前置准备：Notion 数据库

  • 01
    创建数据库

    在 Notion 中创建一个空白数据库

  • 02
    连接集成

    数据库右上角点击 ... → 集成 → 选择你的集成

  • 03
    获取数据库 ID

    从浏览器链接中复制数据库 ID（?v= 前面的 32 位字符）

04

安装插件

  1. 1
    打开 Obsidian
  2. 2
    进入 设置 → 社区插件 → 浏览
  3. 3
    搜索 "Share to NotionNext"
  4. 4
    点击安装，然后启用

💡 提示

插件市场加载慢时可尝试开启代理

05

配置插件

在 Obsidian 设置 → 第三方插件 中找到 "Obsidian to NotionNext"，填入：

API 令牌

Notion API 的 Secret Token

数据库 ID

复制的 32 位数据库 ID

同步字段

category（用于记录同步状态）

⚠️ 自定义属性参考：
title、tags、category、date、Source、status（全部为 Multi-Select 或 Date 类型）
06

创建模板

在 Obsidian 模板文件夹创建模板文件：

--- title: 文章标题 category: - Software - Technical tags: status: - draft - published date: Source: ---

使用：创建笔记 → Alt+E 调出模板，或使用 Template 插件自动化

07

使用方式

  1. 01
    用模板创建笔记

    使用 Alt+E 或 Template 插件快速创建

  2. 02
    写完笔记

    在功能区找到 Notion 图标

  3. 03
    点击同步

    点击「同步到 NotionNext」按钮

  4. 04
    完成！

    笔记已同步到 Notion 数据库，生成博客链接

08

注意事项

  • ✓
    字段一致性

    确保 Notion 数据库字段名称与插件要求一致

  • ✓
    保护隐私

    API Token 不要泄露给他人

  • ✓
    先测试

    首次使用建议先测试单篇笔记同步

  • ✓
    关注更新

    更新插件时注意检查是否有 Breaking Changes
