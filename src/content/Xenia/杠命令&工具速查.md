```
├─ Agent B → article-cover-16x9（封面，文字直接进图）
├─ Agent C → 撰写标题（3 个爆款风格，回显到对话）
├─ Agent D → x-post（即刻版 + X版，回显到对话）
└─ Agent E → beautiful-slides（HTML 幻灯片）
```

## 四、发布 & 社交平台（读写双向）

> 这两个工具同时具备**写入+读取+搜索+互动**能力，是社交运营的核心工具。

| 工具 | 平台 | 能力 | 复制即用 |
|------|------|------|----------|
| jike-web-cli | 即刻 | 发动态 / 查看 feed / 搜索 / 点赞 / 评论 | 帮我用 jike-web-cli 发一条即刻：xxx |
| twitter-cli | X/Twitter | 发推 / 搜索 / 点赞 / 转发 / 查看时间线 / 回复 | 帮我用 twitter-cli 发一条推：xxx |

**单工具高阶：**

- jike-web-cli feed → 查看最新动态流
- jike-web-cli search xxx → 搜索即刻内容
- twitter-cli search xxx → 搜索推文
- twitter-cli like/rt → 点赞/转发
- twitter-cli timeline → 查看关注者最新动态

**组合玩法：**

| 场景 | 复制即用 |
|------|----------|
| 双平台同步发布 | 同时用 jike-web-cli 和 twitter-cli 把这条内容发到即刻和推特，各适配平台风格 |
| 跨平台改写分发 | 先把这篇文章改成即刻短动态（200字以内），再压缩成推特（280字符以内），分别发布 |
| 读取→再创作 | 用 jike-web-cli 看一下即刻热榜，再用 twitter-cli 搜 Twitter 上同一话题的讨论，帮我综合写一篇 |
| 批量互动 | 用 twitter-cli 给今天发的推下面的评论都点个赞，再用 jike-web-cli 回复即刻上的新评论 |
