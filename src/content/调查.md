# 第三轮 · 副业 / 网赚类 CPS 全景

> 调查时间：2026-10-15 · 本轮覆盖：电商联盟、网盘拉新、短剧小说、外卖本地生活、游戏发行人、APP 拉新分发平台、知识付费、海外电商联盟。
> 结论先说：**副业类是 CPS 的大头，门槛低、结算快，但有两个坑必须避开**（一是「拉新分发平台」邀请码鱼龙混杂，二是部分品类规则变动快）。

---

## 一、电商联盟（淘客系）— 长久稳定但抽成低

| 平台 | 佣金规则 | 门槛 | 结算 |
| --- | --- | --- | --- |
| **淘宝联盟** | 商家设置，**技术服务费 10% + 税**；实测常见商品 12%~15% | 需注册淘宝联盟账号 | 每月 20 日结算上月，扣技术服务费和税 |
| **京东联盟** | 官方全域 CPS 平台，按品类比例 | 需注册 + 审核 | 月度结算 |
| **多多进宝** | 拼多多官方 CPS，**佣金最高 50%**，微信生态转化高 | 需注册 | 官方平台结算 |
| **抖音精选联盟** | 达人带货抽佣，**佣金比例由商家设，常见 5%~50%**，平台另收技术服务费 | 需达人/团长资质 | 平台结算 |

**要点**

- 淘客的**真实到手远低于表面佣金**：淘宝抽 10% 技术服务费 + 税，剩下的才是你的。返利 App 通常只把佣金的 85%~95% 返给用户，中间那 5%~15% 是平台赚的
- **多多进宝 50% 上限**是这几个里最高的，适合低价快消品
- 抖音精选联盟的优势是**内容即流量**，有短视频能力的适合；纯发链接不如淘客系直接

**适合你的点**：你是做工具站的，用户是开发者/科技爱好者。适合推**数码配件、键鼠外设、书籍**这几个品类（淘宝「Physical Books」类 4.5%，「PC/PC Components」2.5%），比推服装更贴受众。

---

## 二、网盘拉新 — 单价透明，副业主力

这是副业圈最活跃的品类之一，单价公开可查：

| 平台 | 拉新单价 | 转存收益 | 备注 |
| --- | --- | --- | --- |
| **夸克网盘** | 基础 **7 元/人**（移动端），活动期最高 **13 元/人** | 0.3~0.85 元/次 | 暑期激励（7/16-8/31）移动端 13 元；PC 端转存 0.22 元 |
| **百度网盘** | 需查一级代理平台当期价 | — | 蜂小推等平台有接入 |
| **迅雷云盘** | 需查一级代理平台当期价 | — | 同上 |

**关键机制**

- **夸克官方不对个人开放推广权限**，必须通过一级代理平台（如任推邦、蜂小推）开通
- 叠加收益：拉新 7~13 元 + 转存 0.3~0.85 元/次 + **会员返佣 30%**，综合单用户价值可超 60 元
- 单价随活动浮动，**暑期/开学季是高峰**

**⚠️ 坑点**：一级代理平台质量参差，选平台要看是否「不扣量」。任推邦官方宣传「不扣量、不抽佣」，且有邀请码机制（但你推的是平台本身，不是拉新项目）。

## 三、APP 拉新分发平台 — 副业入口层

这类平台**本身不是 CPS 项目，而是 CPS 项目的分发渠道**——你在上面接任务、领推广码、看结算。

| 平台 | 特点 |
| --- | --- |
| **任推邦** | 聚名科技旗下，宣称 90 万+ 推广达人、累计结算 5 亿+、300+ 合作品牌 |
| **蜂小推** | 合肥蜂推网络科技，2019 年成立，一级渠道商，已接百度/夸克/迅雷网盘 |

**核验状态**：两家官网均可访问（`rentuibang.net`、蜂小推）。但**「官方邀请码」在搜索结果里有多个不同数字**（3881888、5888888、376378、ctm20066280003692 等），说明邀请码分发渠道混乱——**不要轻信搜索结果里的邀请码，以平台注册页实时显示的为准**。

**给你的建议**：这类平台适合**自己做副业接单**，不太适合挂到羊毛站上给用户（因为邀请码不稳定，且平台本身不产生 CPS 价值）。如果要做，做成「副业工具箱」条目而不是「邀请活动」条目。

## 四、外卖 / 本地生活 CPS — 高频低客单

- **美团外卖 CPS**：返利约 **3%~5%**
- **饿了么 CPS**：返利约 **6%**
- 模式：推广优惠券链接，用户领券下单你得返佣；也可以做外卖会员代开（如 6.9 元美团会员）
- 特点：**高频、低客单、需持续流量**，没有流量基本做不动

**判断**：不适合工具站受众，跳过。

## 五、短剧 / 小说 CPS — 2026 新热点

- **短剧 CPS**：通过平台（如抖音小程序短剧）挂载链接，用户充值解锁剧集你得分成
- **小说 CPS**：番茄/七猫等免费阅读平台的拉新 + 充值分成，网文生态成熟
- 常见分发渠道：任推邦、蜂小推等一级平台
- **核验状态**：玩法存在且活跃（大量资源站在做），但**具体分成比例需接入平台后才能看到**，且花样繁多、规则变化快

**⚠️ 风险提示**：短剧资源站和盗版内容高度绑定（搜索结果里大量免费短剧资源站）。**推短剧 CPS 要走官方小程序挂载，不要碰盗版资源分发**——后者有版权风险。

## 六、游戏发行人计划 — 内容型 CPS

- **抖音星图 × 游戏发行人计划**：抖音官方连接游戏厂商与达人的平台，达人创作游戏宣传内容，按效果结算
- **快手磁力聚星**：快手官方达人生态营销平台（原快接单）
- 特点：**需内容创作能力**，不是发链接能做的
- 另有「小游戏厂商配置公会 CPS 收益」能力，偏向 B 端

**判断**：需要短视频创作能力，如果你想拓展视频方向可以研究，纯链接式 CPS 做不了。

## 七、知识付费分销 — 高客单

- 特点：**客单价高、一单顶十单电商**，但需要精准受众

**适合你的点**：你是 AI 工具方向，AI 课程分销（Claude 使用课、AI 编程课）和受众高度重合，比推服装转化好。

# 第四轮 · CPS 具体类型总览（按结算机制分类）

> 调查时间：2026-10-15 · 前三轮按「厂商」查，这一轮按「结算机制」重新归类。
> 为什么这样分：**决定你收益上限的不是厂商，是结算机制**。同样是 10% 佣金，「12 个月持续分成」和「一次性」差 12 倍。

## 一、七种 CPS 结算机制

| 机制 | 一句话定义 | 收益特征 | 代表项目 |
| --- | --- | --- | --- |
| **A. 邀请注册型** | 被邀请人完成注册即得 | 单价低、量大、无门槛 | Muse（10 亿词元）、Manus（500 积分）、硅基流动（16 元额度） |
| **B. 消费返佣型** | 被邀请人下单后按成交额抽成 | 单价高、需真实消费 | 淘宝联盟、京东联盟、多多进宝（最高 50%）、抖音精选联盟 |
| **C. 订阅分成型** | 被邀请人订阅后**持续**抽成 | **收益天花板最高** | Railway（15%×12 个月）、ElevenLabs（22%×12 个月）、Notion（$50+20% 首年）、Netlify（20%） |
| **D. Bounty 动作型** | 完成指定动作得固定金额 | 金额明确、易核算 | Amazon Prime $12、Audible $20~25、Amazon Business $15 |
| **E. 云厂商返现型** | 被邀请人购买云产品返现 | 客单高、可长期复购 | 腾讯云（邀请固定 30%）、阿里云（10%~35%，**续费也返**） |
| **F. 拉新任务型** | 按人头 / 转存次数计费 | 单价透明、走代理平台 | 夸克网盘（7~13 元/人 + 转存 0.3~0.85 元 + 会员 30%） |
| **G. 交易撮合型** | 促成交易或开户得佣金 | 单笔高、低频 | Gate-Card（消费 700 刀我得 5 刀）、环球巴士（会员租赁）、AI 代充 |

## A 套：羊毛雷达站点工作流（照这个走就行）

### 阶段 1 · 选品判断（每次新增条目前过一遍）

四问全过才收录，任一不过就放弃：

| 问题 | 不通过的例子 |
| --- | --- |
| ① 我能拿到奖励吗？ | OpenCode Go（官方已结束） |
| ② 奖励规则官方可查吗？ | 基元律动（页面提示邀请码未参与活动） |
| ③ 用户侧价值成立吗？ | Cloudflare（无返佣但免费额度真香→**放行**） |
| ④ 链接能长期活吗？ | Cursor（计划终止，别再推） |

### 阶段 2 · 取证与写条目

```bash
# 1. 官方 URL 必须实测（状态码 + 正文）
curl.exe -sSL -o NUL -w "%{http_code} %{url_effective}" --max-time 25 \
  -A "Mozilla/5.0 ... Chrome/131.0" <url>

# 2. 页面是 JS 渲染的，用浏览器打开读正文（本次调查全部这么做）
#    重点抓：① 奖励金额 ② 生效条件 ③ 失效条件 ④ 有效期

# 3. 写数据：D:/project2026/网站搭建/token/data-cps.json
#    字段：id / type / name / tagline / myReward / friendReward /
#          code / steps / note / period / cta / url / verified

# 4. 重新生成（脚本会逐条 curl 复检全部 URL，非 200 会打印）
python build-cps.py
```

**字段填写规范**（这次调查踩过坑后定的）：

| 字段 | 写法 |
| --- | --- |
| `verified` | 写实际状态码 + 关键发现，如 `2026-10-15 核验 200 · 落地页显示 Sign up to get 500 credits` |
| `note` | **只写用户必须知道的限制**，不写背景介绍 |
| `cta` | 按真实动作填：前往注册 / 折扣优惠 / 查使用指南 / 立即下单 / 前往购买 |
| `warn` | 官方口径与社区口径不一致时置 `true`，卡片自动打「待确认」 |
| 无返佣条目 | **直接删 `myReward` 和 `friendReward` 字段**，卡片奖励栏自动隐藏 |

### 阶段 3 · 数据生成与冒烟

```bash
python build-cps.py          # 生成 data-cps.js，复检 URL
python -m http.server 8712   # 本地预览
```

浏览器必查五项：

1. 分类 chip 计数 = 实际渲染卡数（防止被过滤逻辑吃掉）
2. 每张卡 `data-search` 能被搜到（搜厂商名试）
3. `cta` 链接是 `https:` + `target=_blank` + `rel="noopener"`
4. 邀请码复制按钮真的写进剪贴板
5. 390px 视口无横向溢出

### 阶段 4 · 部署与更新

- 静态托管（GitHub Pages / Cloudflare Pages），**零构建零后端**
- 每次改 `data-cps.json` → 跑 `build-cps.py` → 推仓库，30 秒生效
- 建议每月跑一次全量 URL 复检，把失效条目挑出来

### 阶段 5 · 迭代

每月做一次：
- **复检**：所有 URL 状态码，失效的下线
- **补规则**：把「待确认」的条目通过实测转成确定数字
- **删条目**：官方计划终止的立刻删（这次就删了 OpenCode Go、上游 4 个关停项目）

## B 套：CPS 生意通用工作流（把站点当获客渠道）

### 阶段 1 · 选品（决定 80% 的收益）

优先级矩阵，按你手头资源选主推：

| 你的资源 | 主推机制 | 代表项目 |
| --- | --- | --- |
| 工具站流量（现状） | **C 订阅分成 + D Bounty** | Railway 15%/年、Amazon Prime $12 |
| 国内云用户 | **E 云厂商返现** | 腾讯 30%、阿里 35% 且续费返 |
| 内容创作能力 | C + B + 课程分销 | 订阅分成保底、内容带货放大、课程吃高客单 |
| 只有微信/群 | **F 拉新 + A 邀请注册** | 夸克 13 元/人、Muse/Manus 注册礼 |

**核心原则**：**优先做「订阅分成型」**。其他类型推一单赚一单，只有订阅分成是「推一次赚一年」。

### 阶段 2 · 账号与渠道准备

按项目准备账号，一次搭好：

| 项目 | 需要什么 | 拿到什么 |
| --- | --- | --- |
| Railway | 免费注册 + workspace | 专属推荐链接（**15%/12 个月**） |
| ElevenLabs | 注册账号 | 推荐链接（**22%/12 个月，$5 起付**） |
| Zeabur | 账号下至少 1 个含 Service 的项目 | 推荐码（阶梯最高 100%） |
| 腾讯云 | 实名腾讯云账号 | 推广大使链接（固定 30%） |
| 阿里云 | 实名阿里云账号 | 云大使链接（10%~35%，续费也返） |
| Amazon Associates | 注册 + 网站审核 | 联盟链接 + Bounty 资格 |
| 硅基流动 | 账号 | 邀请链接（16 元额度） |

> ⚠️ **Zeabur 有个隐藏门槛**：推荐人账号下必须至少有一个含 Service 的项目，否则不能用推荐码。

### 阶段 3 · 链接管理（最容易被忽视的一环）

**规则**

1. **一个项目一条链接，不要多渠道混用**——归因乱了佣金就没了
2. utm 参数统一规范：`?utm_source=site&utm_medium=invite&utm_campaign=<项目>`
3. **邀请码和链接都要给**：有些平台（Muse）只能填码，有些（Manus）只能走链接
4. 建一个表格记录：项目 / 链接 / 邀请码 / 上月点击 / 上月转化 / 上月佣金

**归因陷阱**

- **Notion 是 last-click 归因**——用户点了别人的链接再点你的，佣金归别人
- **Amazon Bounty 有资格窗口**，不是无限期
- 腾讯云/阿里云是**关联期**内首购才返，超期无效

### 阶段 4 · 内容发布与转化

页面已经解决「展示」，剩下的是「让人点」：

**转化率关键点**

| 要素 | 做法 |
|---|---|
| 奖励可视化 | 卡片直接写「我得 X / 你得 Y」，别让用户猜 |
| 操作步骤 | 写清「先注册 A 再用 A 登 B」（Manus & Cue 就是这种两步走） |
| 降低行动门槛 | 邀请码给复制按钮；教程类给「查使用指南」而不是甩官网链接 |
| 稀缺性 | 截止日期标出来，45 天内的自动高亮 |

**内容搭配**（工具站的天然优势）

- 每个条目配一篇「怎么用」：OpenList 部署、AI API 接入、代充教程
- 教程里埋入口：「这篇文章用的服务器是甲骨文白嫖的 → 点这里领」

### 阶段 6 · 合规（这条别省）

| 要求 | 依据 |
| --- | --- |
| **必须披露利益关系** | Notion 官方明确要求 FTC 合规——「必须让人知道你因推广获得报酬」 |
