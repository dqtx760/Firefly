### 方法3

Codex跳过手机验证教程

一、登录网页版 ChatGPT

先登录网页版 ChatGPT，然后打开下面这个地址，获取 ChatGPT session JSON：

https://chatgpt.com/api/auth/session

二、生成 Codex Auth JSON

打开 Codex Auth JSON 生成器：

https://codexauth.moshushi.xyz/

把上一步获取到的 session JSON 粘贴进去，即可生成 Codex 登录所需文件。

三、放置 `auth.json` 文件

下载生成的 `auth.json`，并放到 `.codex` 目录。

### Windows：按 Win + R

```
%USERPROFILE%\.codex
```

macOS：
在「访达」中按 Command + Shift + G，

```
粘贴 ~/.codex，然后回车
```


四、重新登录 Codex

重新登录 Codex 后，即可跳过手机号验证。
