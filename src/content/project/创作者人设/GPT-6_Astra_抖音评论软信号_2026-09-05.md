## 二、用户最头疼的 6 个问题(按热度排)

### 🔴 1. 配置好了,但「列表不显示/接口报错」最扎心

- 「为什么我 Codex 里没有 GPT-6 Astra?」— 全网中文用户最多问的。
- 典型报错:`The 'gpt-6.0-astra' model is not supported when using Codex with a ChatGPT account`(注意是 `gpt-6.0-astra`,跟文档的 `gpt-6-astra` 不是同一个字符串)。**两个 ID 都存在,API 用哪个分场景。**
- 配错之后整个 Codex 调用挂掉。OpenAI 给每天一次 banked usage reset 作为补偿,但用户体感就是「不能用了」。
- 中高频出现:`gpt-6-astra`(API 名) vs `gpt-6.0-astra`(Codex 报错的内部名)。

### 🔴 2. Chat Completions 不能用了,迁移成本大

- 旧 LiteLLM / LangChain 默认走 `v1/chat/completions`,ASTRA 直接拒 tool calls。
- 必须切到 **Responses API**:`model="gpt-6-astra"`,`tools` 移到 Responses 格式,`messages` 改成 `input`。
- `temperature` / `top_p` / `logprobs` 全锁死,**且不会报错,只是静默忽略**。
- 网关层得做 model-specific routing,ASTRA 单独走。

### 🔴 3. 配额太紧 + 任务太贵

- ChatGPT Pro $200/月 — **200 条/周**。reddit/X 上吐槽率第一的就是这。
- API: $10/M input,$50/M output,是 GPT-5.6 Sol 的 2.5 倍。
- Fast Mode:速度 2.5 倍,价格 2 倍。
- UK AISI 测出来自主任务可跑 **30.9 分钟** — 一次任务能烧 1.67 USD(max effort)到更多。
- 缓存输入 $1/M,缓存写入 $12.5/M,这块对长任务不算便宜。

### 🔴 4. 安全监控「突然叫停任务」

- Astra 是 OpenAI 第一个启用了「misalignment 异步监控」的产品。
- API **可能中途返 403**,错误码 `misalignment_policy_violation` — 不能无脑重试,**没有通用 resume 机制**。
- 涉及网安/对抗性任务,可能被路由到 Daybreak Blue/Red(各自映射到 gpt-5.6-sol / gpt-5.6-cyber),你之前调的 ASTRA 直接换成 5.6。
- 防御类工作会被误伤(OpenAI 自己承认)。

### 🔴 5. 装/写代码 OK,碰硬件就翻车

- AIoT 内测反馈:MCP 调用直接**填错设备 ID**,让 1 号读电压结果去停了 2 号;**幻觉会变成物理误动作**。
- 写方案、生成代码、初稿文档很强;**真下到 STM32 / 边缘网关 / 实际硬件,会犯老工程师不会犯的低级错误**。
- 推荐用法:写得对、跑不通就别上线;参数校验、操作审计、关键动作人工确认、硬件侧兜底,四层保险。

### 🔴 6. 长任务不一定长 — 容易卡细节/不收敛

- 「Astra can get absorbed in details, asymptote if not set up carefully」(Manager Loop 评测)。
- Kilo 工程师实测:一晚跑了 ~2000 步,**任务没收敛**。
- OpenAI 自家研究员警告:Astra 思维链(opaque recurrence)**更难监控**,链短了反而难审。

### 🟡 7. 体感「速度慢 + Token 烧得快」

- 跑下来比 GPT-5.6 Sol 慢是常态。
- 超过 **272K 上下文**阈值后,token 消耗进一步爆。
- 一句话:Mass 大、慢、贵,但能一次扛 30 分钟。

### 🟡 8. 视觉/设计不如 Claude

- 几大评测都提到:Astra 后端工程领先,但 UI/UX 与视觉资产仍让位 Claude。
- 你要是做落地页/营销素材/海报,Claude 还值得留一手。

### 🟡 9. Over-engineering bias

- 小修小补请求,Astra 经常回一个 sprawling PR。
- 解法:prompt 里加**显式 minimality 指令**(OpenAI 自己 FrontierCode 提示词也这么干)。

### 🟡 10. 中段上下文会忘

- 微博实测:上下文窗口虽大,**中间部分内容记不全**。
- 不要把"丢进去就万事大吉"当用法,关键信息还是要 anchor 到首/尾。
